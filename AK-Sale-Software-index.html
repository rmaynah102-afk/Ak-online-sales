ဖုန်းပြောင်းမည်၊ Browser Data ဖျက်မည်ဆိုပါက Backup အရင်ထုတ်ပါ။ Backup တွင် စာရင်းဒေတာပါဝင်ပြီး ဓာတ်ပုံများကို သီးခြား Export လုပ်ရန် လိုအပ်သည်။

မျှဝေရန်

Android Share ဖြင့် Viber၊ TikTok စသည်တို့သို့ ပို့နိုင်သည်။ အက်ပ်က တိုက်ရိုက်အလိုအလျောက်တင်ပေးခြင်း မဟုတ်ပါ။

Cloud / Firebase

Cloud Sync သည် အရောင်း၊ ပစ္စည်းစာရင်းနှင့် ဆိုင်အချက်အလက်တို့ကို သိမ်းသည်။ ဓာတ်ပုံများကို ဖုန်းထဲတွင်သာ သိမ်းသည်။ Firestore Rules ကို လုံခြုံစွာ သတ်မှတ်ထားရန် လိုသည်။
Firebase စစ်ဆေးနေသည်

Printer

ဒီ Web App မှာ ဘောင်ချာကို Print ခေါ်နိုင်သည်။ Bluetooth printer အားလုံးကို Browser က တိုက်ရိုက်မချိတ်နိုင်ပါ။ ဖုန်း Print service သို့မဟုတ် printer ထုတ်လုပ်သူ App ကို အသုံးပြုနိုင်သည်။
