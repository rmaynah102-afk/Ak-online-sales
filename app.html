Bluetooth Printer ကို Android Settings မှာ အရင် Pair လုပ်ပါ။ Wi-Fi Printer ကို ဖုန်းနှင့် တူညီသော Wi-Fi Network ချိတ်ပြီး Printer IP နှင့် RAW TCP Port (ပုံမှန် 9100) ထည့်ပါ။ Direct Print သည် APK ထဲတွင်သာ အလုပ်လုပ်ပြီး Website သည် System Print ကို သုံးမည်။
