**အကြောင်းအရာ — AK Sale Software အတွက် တရားဝင် Merchant Payment API အသုံးပြုခွင့်နှင့် နည်းပညာဆိုင်ရာ လမ်းညွှန်ချက် တောင်းခံခြင်း**

လေးစားအပ်ပါသော KBZPay အဖွဲ့သားများခင်ဗျာ/ရှင်၊

ကျွန်ုပ်တို့သည် မြန်မာနိုင်ငံရှိ ဆိုင်ငယ်၊ လက်ကား/လက်လီအရောင်းဆိုင်များအတွက် ရောင်းချမှု၊ ကုန်ပစ္စည်းလက်ကျန်၊ ဘောင်ချာ၊ ငွေစာရင်းနှင့် အရောင်းအစီရင်ခံစာများကို စီမံနိုင်သော **AK Sale Software** ကို တည်ဆောက်လျက်ရှိပါသည်။

ကျွန်ုပ်တို့၏ ရည်ရွယ်ချက်မှာ KBZPay ၏ တရားဝင်ခွင့်ပြုထားသော Merchant API ကိုသာ အသုံးပြုပြီး ဘောင်ချာတစ်ခုချင်းစီအတွက် ငွေပေးချေမှုတောင်းခံခြင်း၊ ငွေပေးချေမှုအခြေအနေကို Server မှ စစ်ဆေးအတည်ပြုခြင်းနှင့် အရောင်းစာရင်းတွင် မှန်ကန်စွာ မှတ်တမ်းတင်ခြင်းတို့ကို ဆောင်ရွက်ရန်ဖြစ်ပါသည်။

ထို့ကြောင့် အောက်ပါအချက်များကို လမ်းညွှန်ပေးပါရန် လေးစားစွာ တောင်းခံအပ်ပါသည်။

1. POS / Online Sales Software အတွက် အသုံးပြုနိုင်သော KBZPay Merchant API သို့မဟုတ် Dynamic QR Payment ဝန်ဆောင်မှု ရှိ/မရှိ။
2. Merchant အဖြစ် လျှောက်ထားရန် လိုအပ်သော မှတ်ပုံတင်စာရွက်စာတမ်းများနှင့် စည်းကမ်းချက်များ။
3. API Documentation၊ Sandbox/Test Account နှင့် စမ်းသပ်အသုံးပြုခွင့်။
4. Payment Status Inquiry၊ Server Webhook/Callback နှင့် လုံခြုံရေးအတည်ပြုနည်းလမ်းများ။
5. Transaction Fee၊ Settlement၊ Transaction Limit၊ Refund/Reversal နှင့် Reconciliation လုပ်ငန်းစဉ်များ။
6. ဆိုင်အများအပြား အသုံးပြုနိုင်သော Software Platform အဖြစ် ချိတ်ဆက်ရာတွင် လိုအပ်သည့် Merchant Account ဖွဲ့စည်းပုံနှင့် ခွင့်ပြုချက်များ။

ငွေပေးချေမှုအတည်ပြုခြင်းကို KBZPay ၏ တရားဝင် Server API နှင့် လုံခြုံသော Callback စနစ်မှသာ ဆောင်ရွက်မည်ဖြစ်ပြီး ငွေလွှဲ Screenshot၊ Customer ပေးပို့သော စာရွက် သို့မဟုတ် App ထဲရှိ Client-side အချက်အလက်တစ်ခုတည်းကို ငွေလက်ခံရရှိကြောင်း သက်သေအဖြစ် မသတ်မှတ်ပါ။

API Key၊ Secret၊ PIN၊ OTP နှင့် အခြားလုံခြုံရေးအချက်အလက်များကို Public Source Code တွင် မထည့်သွင်းဘဲ KBZPay မှ သတ်မှတ်ပေးသော လုံခြုံသည့်နည်းလမ်းဖြင့်သာ စီမံသိမ်းဆည်းမည်ဖြစ်ပါသည်။
