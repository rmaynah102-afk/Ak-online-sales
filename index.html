  1. Web App ကိုဖွင့်ပြီး Gmail ဖြင့် Login ဝင်ပါ။
  2. ဆိုင်အမည်၊ ဖုန်း၊ လိပ်စာနှင့် ဆိုင်အချက်အလက်များကို ဖြည့်ပါ။
  3. ပစ္စည်းအမည်၊ ကုဒ်၊ အရင်းဈေး၊ ရောင်းဈေးနှင့် လက်ကျန်ကို ထည့်ပါ။ Barcode အတွက် 📷 Scan ကိုနှိပ်ပြီး ကင်မရာခွင့်ပြုပါ။
  4. အရောင်းစာမျက်နှာတွင် ပစ္စည်းရွေးပြီး အရေအတွက်နှင့် ငွေပေးချေမှုကို မှတ်တမ်းတင်ပါ။

၂။ နေ့စဉ်လုပ်ငန်းစဉ်

  • ပစ္စည်း: ပစ္စည်းအသစ်ထည့်၊ ဈေးနှုန်းနှင့် လက်ကျန်ပြင်ဆင်ပါ။
  • အဝယ်: Supplier ထံမှ ဝယ်ယူမှုကို မှတ်တမ်းတင်ပါ။
  • အရောင်း: ငွေအပြည့်၊ တစ်စိတ်တစ်ပိုင်း သို့မဟုတ် အကြွေးအဖြစ် မှတ်တမ်းတင်ပါ။
  • Customer/Supplier: ဖောက်သည်၊ ပေးရန်/ရရန်စာရင်းကို စစ်ဆေးပါ။
  • အစီရင်ခံစာ: အရောင်း၊ အသုံးစရိတ်နှင့် အမြတ်စာရင်းကို ပြန်စစ်ပါ။

၃။ Backup နှင့် ဖုန်းပြောင်းခြင်း

  1. Backup / Settings စာမျက်နှာကို ဖွင့်ပါ။
  2. Backup JSON ကို Export လုပ်ပြီး ဖုန်းပြင်ပ လုံခြုံသောနေရာတွင် သိမ်းပါ။
  3. ဖုန်းအသစ်တွင် Login ဝင်ပြီး လိုအပ်ပါက Backup ကို Restore လုပ်ပါ။
  4. Restore မလုပ်မီ လက်ရှိဒေတာကိုလည်း Backup ထပ်ယူပါ။

  • Cashier: အရောင်း၊ ငွေလက်ခံမှုနှင့် ဘောက်ချာ။
  • Employee: ခွင့်ပြုထားသော လုပ်ငန်းတာဝန်များသာ။

Release APK မထုတ်ရသေးပါက Download ခလုတ်မှ ဖိုင်မရနိုင်သေးပါ။ လက်မှတ်ထိုးပြီး Release ထုတ်ပြီးမှ ရောင်းချဖြန့်ဝေပါ။

၁။ APK ရယူရန်

  1. APK Build / Download ကိုနှိပ်ပါ။
  2. နောက်ဆုံးအောင်မြင်သော Build ကိုဖွင့်ပါ။
  3. Artifacts အောက်မှ AK-Sale-Software-debug-APK ကို Download လုပ်ပါ။
  4. ZIP ဖိုင်ကိုဖြည်ပြီး APK ဖိုင်ကို ရွေးပါ။

၂။ Android ဖုန်းတွင် ထည့်သွင်းရန်

  1. Download လုပ်ထားသော APK ကိုနှိပ်ပါ။
  2. Android က တားလျှင် သက်ဆိုင်ရာ Browser / File Manager အတွက် “Install unknown apps” ခွင့်ပြုပါ။
  3. Install ကိုနှိပ်ပြီး App ကိုဖွင့်ပါ။
  4. Google Play Protect သတိပေးချက်ကို မျက်ကွယ်မပြုဘဲ APK ၏ Source နှင့် Signature ကို စစ်ဆေးပါ။ မယုံကြည်ရသော APK ကို မတပ်ဆင်ပါနှင့်။

၃။ Update လုပ်ရန်

နောက်ဗားရှင်းကို တပ်ဆင်ရာတွင် ယခင် APK နှင့် တူညီသော Android package ID နှင့် signing key လိုအပ်သည်။ App ကို uninstall မလုပ်မီ Backup JSON ထုတ်ထားပါ။ Signing key ပျောက်ဆုံးပါက ရှိပြီးသား App ကို ပုံမှန် Update မလုပ်နိုင်ပါ။

၄။ ရောင်းချမည့်အခါ မဖြစ်မနေစစ်ရန်

  • Gmail Login၊ Firebase Cloud Sync နှင့် ဆိုင်တစ်ဆိုင်ချင်းစီ data ခွဲထားမှုကို ဖုန်းနှစ်လုံးဖြင့် စမ်းရန်။
  • Printer၊ Backup/Restore၊ အရောင်း၊ အကြွေးနှင့် KPay လုပ်ငန်းစဉ်များကို စမ်းရန်။
  • အသုံးပြုသူလက်စွဲ၊ Version၊ Support ဆက်သွယ်ရန်နှင့် ဈေးနှုန်းကို ထည့်ရန်။

လက်ရှိ Build အခြေအနေနှင့် Artifact ရရှိမှုကို GitHub Actions ထဲတွင် အတည်ပြုပါ။ Build အောင်မြင်ခြင်းတစ်ခုတည်းသည် Release APK ကို လုံခြုံစိတ်ချစွာ ရောင်းချရန် အသင့်ဖြစ်ကြောင်း မဆိုလိုပါ။
