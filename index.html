Social Media ကြော်ငြာဖန်တီးရန်

ပစ္စည်းစာရင်းမှ ရွေးလိုက်ရုံဖြင့် အမည်၊ ဈေးနှုန်းနှင့် ဓာတ်ပုံကို ဖြည့်ပေးမည်။ Share ခလုတ်မှ Android Share Menu ကိုဖွင့်ပြီး Facebook၊ TikTok၊ Viber၊ Telegram သို့မဟုတ် အခြား App ကိုရွေးနိုင်သည်။

Share လုပ်ခြင်းသည် ဖုန်းတွင် ထည့်သွင်းထားသော App များ၏ Share လုပ်ဆောင်ချက်ကို အသုံးပြုသည်။ Platform တစ်ခုချင်းစီ၏ ခွင့်ပြုချက်မရှိဘဲ အလိုအလျောက် Post တင်ခြင်း မလုပ်ပါ။

Backup / Restore

ပစ္စည်း၊ အရောင်း၊ အဝယ်၊ လူစာရင်း၊ အကြွေးဆပ်မှတ်တမ်းနှင့် အသုံးစရိတ်အားလုံးကို JSON ဖိုင်အဖြစ် ထုတ်နိုင်သည်။

အသုံးပြုခွင့် / လစဉ်ကြေး

စမ်းသုံးကာလနှင့် Subscription သက်တမ်းကို Server မှ စစ်ဆေးသည်။ သက်တမ်းတိုးရန် KPay ငွေလွှဲပြီး အောက်ပါအချက်အလက်ဖြင့် တောင်းဆိုပါ။

ဆိုင် Account UID: Login ဝင်ပြီးမှ ပြမည်

အသုံးပြုခွင့် မစစ်ရသေးပါ။

ငွေလွှဲ Screenshot ကို Admin ထံ Viber / Telegram မှ ပို့ပါ။ အတည်ပြုပြီးမှ သက်တမ်းတိုးမည်။

Admin သက်တမ်းတိုးရန်

Admin အီးမေးလ်ဖြင့် Login ဝင်ထားသူသာ Server က ခွင့်ပြုသည်။ Customer UID၊ ရက်အရေအတွက်နှင့် ငွေလွှဲအချက်အလက် ထည့်ပါ။

Firebase Cloud Sync ချိတ်ဆက်ရန်

Firebase Project Config ထည့်ပြီး Email/Password Authentication နှင့် Firestore ဖွင့်ထားမှ အလုပ်လုပ်မည်။ Firestore Security Rules ကို မိမိ UID အလိုက် ကန့်သတ်ရမည်။

Firebase မချိတ်ရသေးပါ။
