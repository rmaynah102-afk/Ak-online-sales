ကုန်မာနှင့် လျှပ်စစ်ပစ္စည်းဆိုင်များအတွက် အရောင်း၊ ဝယ်ယူမှု၊ ကုန်ပစ္စည်းလက်ကျန်၊ အကြွေးနှင့် အမြတ်စာရင်းများကို တစ်နေရာတည်းတွင် စီမံနိုင်ရန် ရည်ရွယ်ထားသော ဆိုင်သုံးစနစ်။

APK ရယူရန် / Releaseအများကြည့် ကြော်ငြာများ

APK ပုံစံနှင့် အပြင်ပိုင်း

ဖုန်းပေါ်မှာ ဘယ်လိုမြင်ရမလဲ — အတိုချုံး

1ပင်မစာမျက်နှာ

ယနေ့အရောင်း၊ အမြတ်ခန့်မှန်း၊ ပစ္စည်းအရေအတွက်နှင့် အကြွေးအကျဉ်းချုပ်။

2အောက်/အပေါ် မီနူး

အရောင်း၊ ပစ္စည်း၊ ဝယ်ယူမှု၊ ဖောက်သည်၊ ကုန်ကျစရိတ်နှင့် အစီရင်ခံစာများကို ခွဲထားမည်။

3ဆိုင်အမည်ပါ ဘောင်ချာ

ဆိုင်အမည်နှင့် အရောင်းအသေးစိတ်ပါသော ဘောင်ချာကို Print ထုတ်နိုင်ရန်။

4ဖုန်းသုံးရလွယ်သောပုံစံ

စာရင်းဇယားများ၊ ခလုတ်များနှင့် ဖြည့်စွက်ရန်နေရာများကို ဖုန်းမျက်နှာပြင်နှင့် ကိုက်ညီစေမည်။

အတွင်းပိုင်း လုပ်ဆောင်ချက်များ

ဆိုင်တစ်ဆိုင်ရဲ့ နေ့စဉ်အလုပ်စဉ်ကို အပိုင်းလိုက်စီထားသည်။

ကုန်ပစ္စည်းစာရင်း

ပစ္စည်းအမည်၊ ကုဒ်၊ အမျိုးအစား၊ ဝယ်ဈေး၊ လက်လီ/လက်ကားဈေး၊ လက်ကျန်နှင့် ဓာတ်ပုံ။

ဝယ်ယူမှု

ပေးသွင်းသူ၊ ဝယ်ယူအရေအတွက်၊ ကျသင့်ငွေနှင့် ပေးချေမှုကို မှတ်တမ်းတင်ရန်။

အရောင်း

ပစ္စည်းရွေး၊ အရေအတွက်ထည့်၊ ဈေးနှုန်းတွက်ပြီး ငွေသား/အကြွေး/တစ်စိတ်တစ်ပိုင်း မှတ်ရန်။

ဖောက်သည်နှင့် အကြွေး

ဖောက်သည်စာရင်း၊ ရရန်/ပေးရန်နှင့် ပေးချေမှုမှတ်တမ်း။

အသုံးစရိတ်

နေ့စဉ်ဆိုင်စရိတ်များကို မှတ်တမ်းတင်ရန်။

အစီရင်ခံစာ

အရောင်း၊ အမြတ်/အရှုံး၊ လက်ကျန်နှင့် စာရင်းချုပ်များ။

Backup နှင့် Print

ဒေတာအရန်သိမ်းခြင်း၊ ပြန်ယူခြင်းနှင့် Android Print Service အသုံးပြုခြင်း။

အကောင့်နှင့် ခွင့်ပြုချက်

အသုံးပြုပုံ — တစ်ဆင့်ချင်း

1
APK ကို ဖုန်းထဲထည့်ပါ

ယုံကြည်စိတ်ချရသော တရားဝင် Release မှ APK ကို ရယူပြီး Install လုပ်ပါ။

2
ဆိုင်အကောင့် ဝင်ပါ

သတ်မှတ်ထားသော Gmail ဖြင့် Login ဝင်ပြီး ဆိုင်အချက်အလက်ကို စတင်ပြင်ဆင်ပါ။

3
ကုန်ပစ္စည်းထည့်ပါ

ကုန်ပစ္စည်းအမည်၊ ဝယ်ဈေး၊ ရောင်းဈေးနှင့် စတင်လက်ကျန်ကို ဖြည့်ပါ။

4
ဝယ်ယူမှုနှင့် အရောင်းတင်ပါ

ပစ္စည်းဝယ်တိုင်း Purchase၊ ရောင်းတိုင်း Sale ထဲတွင် မှတ်တမ်းတင်ပါ။

5
စာရင်းနှင့် အကြွေးစစ်ပါ

နေ့စဉ်အရောင်း၊ ကုန်ကျစရိတ်၊ ရရန်/ပေးရန်နှင့် အမြတ်စာရင်းကို စစ်ဆေးပါ။

6
Backup ပုံမှန်သိမ်းပါ

ဖုန်းပြောင်းမည် သို့မဟုတ် Browser/App ဒေတာရှင်းမည်ဆိုပါက အရင် Backup ထုတ်ပါ။
